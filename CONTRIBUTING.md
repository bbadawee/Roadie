# Contributing to Roadie

We welcome PRs across UI polish, rotary/D-pad focus navigation, SponsorBlock integration, AAOS `CarUxRestrictionsManager` hardware integration, and keyboard localization!

## Local Setup

1. JDK 17 or 21
2. Android SDK (API 35)
3. Run unit tests and debug build before opening a PR:

```bash
./gradlew testDebugUnitTest assembleDebug
```
